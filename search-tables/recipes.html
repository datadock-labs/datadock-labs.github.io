10 ready-to-use Confluence searches

Each recipe below is a search you can show as a live table on a Confluence Cloud page with Search Tables. Open the macro, switch to the CQL tab, paste the query and adjust the names in quotes. Most of them can also be built with the Filters tab, without writing any CQL.

All queries on this page are standard Confluence Query Language (CQL) and were run against a Confluence Cloud site in November 2026. currentSpace() means "the space this page is in", and currentUser() means "the person looking at the page", so every reader gets their own result.

1. Pages nobody has edited for six months

A review list for stale documentation, oldest first.

type = page AND space = currentSpace() AND lastmodified < now("-26w") ORDER BY lastmodified ASC

Suggested columns: title, last modified, modified by. Change -26w to -52w for a yearly review.

2. Release notes index

Every page labelled release-notes, newest first.

type = page AND label = "release-notes" ORDER BY created DESC

With filters: Content types Page, Labels release-notes, Sort by Created (newest first).

3. Meeting notes in this space

Confluence's meeting notes template adds the label meeting-notes to each page it creates.

type = page AND label = "meeting-notes" AND space = currentSpace() ORDER BY created DESC

4. Pages that carry two labels at once

For example policies that are also approved.

type = page AND label = "policy" AND label = "approved"

With filters: enter both labels and set Label match to All of these labels.

5. What changed this week under one page

Recent edits in one branch of the page tree. Replace 123456 with the ID of the parent page (the number in its URL).

ancestor = 123456 AND lastmodified >= now("-7d") ORDER BY lastmodified DESC

With filters: Under page (page ID) plus Last modified Last 7 days.

6. My pages

Pages created by whoever is viewing the table. Useful on a team home page: each person sees their own list.

type = page AND creator = currentUser() ORDER BY created DESC

With filters: set Created by to Me.

7. Pages I have edited

type = page AND contributor = currentUser() ORDER BY lastmodified DESC

With filters: set Edited by to Me.

8. Attachments in this space

All files attached to pages of the current space, newest first. Add a word from the file name to narrow it down.

type = attachment AND space = currentSpace() ORDER BY created DESC
type = attachment AND space = currentSpace() AND title ~ "invoice"

9. Blog posts published this month

type = blogpost AND created >= startOfMonth() ORDER BY created DESC

Use startOfYear() for the whole year, or now("-30d") for the last 30 days.

10. A content inventory of a space, exported to CSV

List every page and blog post of a space, then press Export CSV above the table to open it in Excel or Google Sheets. Replace ENG with your space key.

space = "ENG" AND type in (page, blogpost) ORDER BY title

The table pages through all results. CSV export is limited to 2,000 rows per export.

Share a search with your team

When a query is useful to more than one page, save it in the macro dialog as a shared saved search. Anyone can then load it into their own table with one click, and tables can stay in sync when the shared search changes.

Good to know

  • Every search runs with the permissions of the person viewing the page. Two readers can see different results for the same table.
  • If a query has a mistake, the table shows a clear message instead of a broken page.
