How to list all Confluence pages you created

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

Short answer: Use CQL: type = page AND creator = currentUser(). creator is the person who created the page; contributor is anyone who edited it, which is why some searches for "my pages" also return pages you only touched. In a Search Tables macro, currentUser() means the person viewing the page, so one table on a team page shows every reader their own pages.

The query

type = page AND creator = currentUser() ORDER BY created DESC

Pages you edited, created or not: type = page AND contributor = currentUser() ORDER BY lastmodified DESC. Add AND space = "ENG" to stay in one space, or use type in (page, blogpost) to include your blog posts.

Step by step

  1. Edit a page (your personal space's overview works well), type /Search Tables and stay on the Filters tab.
  2. Set Created by to Me, Content types to Page, and Sort by to Created (newest first). For pages you edited, set Edited by to Me instead.
  3. Choose the columns Title, Space, Created, Last modified and Modified by.
  4. Save. Press Export CSV if you need the list elsewhere, for example before handing over your pages when you change teams.

Compared with what Confluence offers built in

  • Search with the contributor filter: matches pages a person created or edited, so it is not a clean "created by me" list.
  • Content by User macro: lists everything one named person created (including comments and spaces) and is tied to the legacy editor.
  • Search Tables: created or edited, pages only or any type, for whoever is viewing; sortable and exportable.

FAQ

Can I list the pages of a colleague instead of mine? Yes, on the CQL tab: creator = "<account ID>". The Filters tab only offers Anyone and Me.

Will a colleague see my private pages in their table? No. The search runs with each viewer's own permissions.

How many rows can I export? Up to 2,000 per export.
