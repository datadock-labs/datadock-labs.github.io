How to export Confluence search (CQL) results to CSV or Excel

Short answer: Confluence Cloud's search page and its built-in report macros do not offer a CSV download of their results. Put the same search into a Search Tables macro (simple filters or CQL) and press Export CSV above the table. You get up to 2,000 rows with the columns you chose, including a link to every page, in a file that opens correctly in Excel and Google Sheets.

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

Example queries worth exporting

Every page changed in a date range, for an audit or a monthly report (this one covers all of October 2026: the second date is the day after the range ends):

type = page AND lastmodified >= "2026-10-01" AND lastmodified < "2026-11-01" ORDER BY lastmodified DESC

A space inventory: all pages and blog posts of one space, A to Z.

space = "ENG" AND type in (page, blogpost) ORDER BY title

Everything one team labelled for review:

type = page AND label = "needs-review" ORDER BY created ASC

Step by step

  1. Edit any page, type /Search Tables. Build the search in the Filters tab (for a date range choose Last modified Custom range), or paste CQL into the CQL tab.
  2. Choose the columns you want in the file. Each table column becomes one or two CSV columns (see below).
  3. Save the macro. In view mode press Export CSV above the table. A message shows the progress ("Exporting 300 of 1,234…").
  4. Open the downloaded file in Excel or Google Sheets.

If the browser blocks the download (some block a second automatic download from the same site), choose Show CSV in the message and copy the data instead.

What is in the file

Column in the tableColumns in the CSV
TitleTitle, URL
TypeType (Page, Blog post, Comment, Attachment …)
SpaceSpace, Space key
Created by / Modified byCreated by / Modified by (display names)
Created / Last modifiedCreated (UTC) / Last modified (UTC), as ISO dates, e.g. 2026-11-14T10:21:07.000Z
LabelsLabels, comma-separated in one cell

Example of the first lines of a file (sample content):

Title,URL,Space,Space key,Last modified (UTC),Labels
Data export API,https://your-site.atlassian.net/wiki/spaces/ENG/pages/…,Engineering,ENG,2026-11-14T10:21:07.000Z,"api, q4"
Onboarding flow notes,https://your-site.atlassian.net/wiki/spaces/ENG/pages/…,Engineering,ENG,2026-11-03T15:40:12.000Z,

The file is UTF-8 with a byte order mark, so accented and non-Latin characters show correctly when Excel opens it. Cells that a spreadsheet could read as a formula (starting with =, +, - or @) are escaped.

Compared with what Confluence offers built in

  • Search page / advanced search: runs the same CQL, but has no CSV or Excel download of the result list.
  • Page and space export (PDF, Word, HTML, XML): exports page content, not a list of search results with their metadata.
  • Report macros: Content by Label and Page Properties Report have no download. Getting Page Properties Report data out is an open request in Atlassian's public tracker (CONFCLOUD-71387). Search Tables does not read page properties today.
  • REST API: can return the same data if you write a script. Search Tables gives you the file without code.

FAQ

Is there a row limit? Yes: 2,000 rows per export. The table on the page itself pages through all results. For bigger lists, split the search, for example by date range or by space, and export each part.

Will the export include pages I cannot see? No. The search, and therefore the file, runs with the permissions of the person who presses the button.

Why are the dates in UTC? So that files exported by people in different time zones match. Spreadsheets can convert them to local time.

Can I hide the button? Yes. In the macro settings, turn off Show the Export CSV button.

Is the data sent anywhere? No. The app runs on Atlassian's platform and the file is built in your browser; no data leaves Atlassian. See the privacy policy.
