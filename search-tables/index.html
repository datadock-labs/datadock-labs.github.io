Search Tables for Confluence

Show any Confluence search as a live, sortable table on your pages. Use simple filters or CQL, save searches for yourself or your team, and export results to CSV. Built on Forge and eligible for Runs on Atlassian: no data leaves Atlassian.

Install

A Confluence Cloud site admin installs the app from the Atlassian Marketplace. No setup is needed after installation.

Add a table to a page

  1. Edit a page, type /Search Tables and press Enter. The configuration dialog opens.
  2. Filters tab: combine text, title, spaces (including "current space"), content types, labels (any or all), "created by me", "edited by me", last modified (presets or a date range) and a parent page.
  3. Or use the CQL tab and write a Confluence Query Language query, for example space = ENG and label = "release-notes" order by lastmodified desc. Invalid queries show a clear message.
  4. Choose the columns (title, type, space, created by, created, last modified, modified by, labels), the default sort and the rows per page (10, 25, 50 or 100). A live preview shows the result.
  5. Save. Readers can sort by title, created or last modified across the whole result set and move between pages.

Saved searches

  • In the dialog, save the current search as personal (only you) or shared (everyone on the site).
  • Load a saved search into any macro with one click, and keep the table in sync with later changes to a shared search.
  • Manage all saved searches on the Search Tables page in the Confluence Apps menu.

Export to CSV

Use Export CSV above a table to download up to 2,000 rows, ready for Excel or Google Sheets. Cells that could be read as spreadsheet formulas are escaped. If your browser blocks a second automatic download from the same site, use the Show CSV option in the message to copy the data.

Permissions and security

  • Every search runs as the person viewing the page, so restricted content never appears for people who cannot open it.
  • Scopes: search:confluence (run searches as the viewer) and storage:app (saved searches). No external servers and no egress.
  • Details: privacy policy.

FAQ

Why does a colleague see fewer results? Results follow each viewer's permissions.

Is there a row limit? The table pages through all results; CSV export is limited to 2,000 rows.

Does it work with Confluence Data Center? No, Confluence Cloud only.
