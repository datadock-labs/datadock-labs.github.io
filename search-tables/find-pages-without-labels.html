How to find Confluence pages that have no labels

Short answer: Confluence's search language cannot do it directly. CQL has no "label is empty" test (label IS EMPTY and label is null both fail with "Could not parse cql"), and the Content by Label macro only lists pages that do have a label. The dependable workaround is to list every page of the space together with its labels, export that list to CSV and filter the empty Labels cells in Excel or Google Sheets. With Search Tables that takes about a minute.

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today. A direct "pages without labels" option is planned for a later version; it is not available yet.

The query

All pages of one space, sorted by title. Replace ENG with your space key.

type = page AND space = "ENG" ORDER BY title

If you only care about pages that are missing one particular label, CQL can do that directly:

type = page AND space = "ENG" AND label not in ("reviewed") ORDER BY title

Step by step

  1. Edit any page, type /Search Tables and open the CQL tab. (Or use the Filters tab: pick the space and the content type Page.)
  2. Paste the first query and choose the columns Title, Labels, Created by and Last modified.
  3. Save, then press Export CSV above the table. The file has one row per page, with the page URL next to the title and the labels as a comma-separated cell.
  4. Open the file in Excel or Google Sheets, turn on a filter for the Labels column and choose (Blanks). What is left is your list of unlabelled pages, each with a link to open and fix it.

Already in the table, you can scan the Labels column by eye: unlabelled pages show an empty cell.

Compared with what Confluence offers built in

  • Content by Label: lists pages that have labels; it cannot list pages without any. This is an open request in Atlassian's public tracker: CONFCLOUD-43823.
  • CQL / advanced search: cannot test for an empty field (CONFCLOUD-76379), so no single query returns only unlabelled pages.
  • Search Tables today: gives you the full list with a Labels column and a CSV export, so the last step happens in a spreadsheet. It is a workaround, not a one-click report.

FAQ

How many pages can I export at once? Up to 2,000 rows per export. For bigger spaces, split the list, for example by date: add AND created < "2025-01-01" for one file and AND created >= "2025-01-01" for the next.

Can I sort the table by the Labels column? No. The table sorts by title, created or last modified across the whole result. Use the spreadsheet for label filtering.

Will people see pages they cannot open? No. The search runs with the viewer's permissions, so the list (and the CSV) only contains pages that person can see.

Does this work for blog posts too? Yes. Use type in (page, blogpost).
