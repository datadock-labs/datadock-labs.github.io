How to list all pages under a Confluence page with their last modified date

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

Short answer: Use the CQL field ancestor: type = page AND ancestor = 123456 returns every page below page 123456, children, grandchildren and deeper. The Children Display macro can sort by modification date but does not show the date or the editor. In a Search Tables macro you get the whole subtree as a table with Last modified and Modified by columns, and a CSV.

The query

type = page AND ancestor = 123456 ORDER BY lastmodified DESC

To find the page ID, open the parent page: it is the number in the address, …/wiki/spaces/ENG/pages/123456/Page+title. Only the direct children: parent = 123456.

Step by step

  1. Edit the parent page (or any other page), type /Search Tables and stay on the Filters tab.
  2. Enter the parent's ID in Under page (page ID, optional), set Content types to Page and Sort by to Last modified (newest first).
  3. Choose the columns Title, Last modified, Modified by, Created by and Labels.
  4. Save. The table stays current as pages are added or edited. Press Export CSV for a snapshot.

What you get

Real output from our test site, 17 Nov 2026: all 3 pages under a test parent page (two children and one grandchild). The table shows the columns in its fixed order. The test account's name is shown as “Demo user”; dates are shortened to YYYY-MM-DD.

Compared with what Confluence offers built in

  • Children Display: titles (optionally an excerpt) in tree order; no date or editor columns, no export.
  • Recently Updated: can be limited to spaces and labels, not to one page and its descendants.
  • Search Tables: any depth, your choice of columns, server-side sorting by title, created or last modified, CSV.

FAQ

Is the parent page itself in the list? No, ancestor returns only the pages below it.

Can I find stale pages in the subtree? Yes: add AND lastmodified < now("-26w") on the CQL tab.

How many rows can I export? Up to 2,000 per export.
