How to search several Confluence spaces at once and show one list

Short answer: use space in ("ENG", "OPS") in CQL. It searches exactly the spaces you name and nothing else. In a Search Tables macro you can pick the spaces in the Filters tab without writing CQL, add a Space column, and readers get one sortable table that covers all of them.

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

The query

Pages changed in the last 30 days in two spaces, newest first. Use your own space keys (shown in each space's URL after /spaces/).

type = page AND space in ("ENG", "OPS") AND lastmodified >= now("-30d") ORDER BY lastmodified DESC

The current space plus one more:

type = page AND (space = currentSpace() OR space = "OPS") ORDER BY lastmodified DESC

Everything with a label across three spaces:

type in (page, blogpost) AND space in ("ENG", "OPS", "SUP") AND label = "incident" ORDER BY created DESC

Step by step

  1. Edit a page, type /Search Tables.
  2. In the Filters tab, choose two or more spaces under Spaces (you can include Current space). Add a content type, labels or a "last modified" period if you need them.
  3. Choose the columns. Include Space so readers can see where each result lives.
  4. Pick the sort (for example Last modified (newest first)) and save. The live preview shows the result before you save.

Prefer CQL? Open the CQL tab and paste one of the queries above.

Compared with what Confluence offers built in

  • Confluence search page: you can filter by several spaces there too, but the result is a search page you open each time, not a list that lives on a page for your team.
  • Livesearch macro: a search box for readers to type into. Searching several chosen spaces from it is an open request in Atlassian's public tracker: CONFCLOUD-37239. Search Tables does not add a search box; it shows a fixed search as a table, so it covers this only when you know the search in advance.
  • Content by Label and Recently Updated: can be limited to several spaces, but show a simple list without columns you choose or CSV export.

FAQ

Can readers sort the table by space? No. Confluence's search does not support sorting by space (it returns an error), so the table sorts by title, created or last modified. The Space column still shows where each result is.

Can I search all spaces? Yes: leave the space out of the query. Results still only include what each reader is allowed to see.

Does this include personal spaces? Only if you name them. A personal space key starts with ~; put it in quotes like any other key.

Can I export the combined list? Yes, with Export CSV (up to 2,000 rows). The CSV has both the space name and the space key. See exporting search results to CSV.
