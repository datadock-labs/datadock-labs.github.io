How to list every Confluence page where you are @mentioned

Short answer: Confluence Cloud has no page or macro that lists everything that mentions you, but its search language can find it. The CQL query mention = currentUser() returns every page, blog post and comment that @mentions the person running the search. Put that query in a Search Tables macro and each reader of the page sees their own list of mentions, newest first.

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

The query

type in (page, blogpost, comment) AND mention = currentUser() ORDER BY lastmodified DESC

To list the mentions of one specific person instead of the reader, use their Atlassian account ID (the long ID at the end of their profile URL; the one below is only an example):

mention = "5b10a2844c20165700ede21g" ORDER BY lastmodified DESC

Narrow it down to one space or to the last month:

mention = currentUser() AND space = currentSpace() AND lastmodified >= now("-30d") ORDER BY lastmodified DESC

Step by step

  1. Edit the page where the list should live (a personal home page or a team dashboard works well) and type /Search Tables.
  2. Open the CQL tab and paste the first query above.
  3. Under columns pick Title, Type, Space, Modified by and Last modified. The Type column tells pages, blog posts and comments apart.
  4. Choose 25 or 50 rows per page, check the live preview, and save.

Because the query uses currentUser(), one table serves everybody: each person who opens the page sees the content that mentions them.

We ran these queries on a Confluence Cloud test site in November 2026. Mentions in the page body and in comments were both found. A brand-new mention can take a short while (about half a minute in our test) to appear, because Confluence has to index it first.

Compared with what Confluence offers built in

  • Notifications: Confluence notifies you when someone mentions you, which is fine for new mentions. It is not a list you can sort, filter by space, or keep on a page, and older mentions are hard to find again.
  • Report macros: none of the built-in macros (Content by Label, Page Properties Report, Recently Updated) can filter by mention. A request for such a list is open in Atlassian's public tracker: CONFCLOUD-71883, and a related one for a "content by mentioned user" macro: CONFCLOUD-33832.
  • Confluence search page: you can type the same CQL into advanced search, but you get a search result page, not a table that lives on a page and stays up to date.

FAQ

Will a colleague see the pages that mention me? No. With currentUser() each reader sees their own mentions. Every search also runs with the reader's own permissions, so restricted pages never appear for people who cannot open them.

Does it find mentions of a group or a team? No. The mention field matches people. Mentions of groups are a separate open request (CONFCLOUD-23015).

Can I get this list into Excel? Yes. Press Export CSV above the table (up to 2,000 rows). See exporting search results to CSV.

Why does a comment show up as "Re: page title"? That is how Confluence names comments in search results, so you can see which page the comment is on. Leave comment out of the query if you only want pages and blog posts.
