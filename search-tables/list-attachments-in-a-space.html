How to list all attachments in a Confluence space

Search Tables is a new Confluence Cloud app and is coming soon to the Atlassian Marketplace (it is in Atlassian's review now). The steps below describe what the app does today.

Short answer: In Confluence Cloud the full attachment list of a space sits in space settings, which only space admins can open. Any user can get the same kind of list with CQL: type = attachment AND space = "ENG". In a Search Tables macro this becomes a table of files, with who uploaded them and when, that you can keep on a page and export to CSV.

The query

type = attachment AND space = "ENG" ORDER BY created DESC

Only files added this year: add AND created >= "2026-01-01". Several spaces: space in ("ENG", "OPS").

Step by step

  1. Edit a page, type /Search Tables and stay on the Filters tab.
  2. Under Spaces pick your space, under Content types pick Attachment, and sort by Created (newest first). (Or paste the query above on the CQL tab.)
  3. Choose the columns Title (the file name), Space, Created by, Created and Last modified.
  4. Save, then press Export CSV if you need the list in a spreadsheet.

What you get

Real output from our test site, 17 Nov 2026: all 5 rows for the space (ENG-default is the space logo). The test account's name is shown as “Demo user”; dates are shortened to YYYY-MM-DD.

Compared with what Confluence offers built in

  • Space settings → Attachments: the complete list, but only for space admins, and it cannot be placed on a page.
  • Attachments macro: lists the files of one page, not a whole space.
  • Search Tables: any user, one or several spaces (pick them under Spaces), results limited to what the viewer can see.

FAQ

Does the table show file sizes? No. The columns are title, type, space, created by, created, last modified, modified by and labels.

Can I list attachments together with pages? Yes: type in (page, attachment), and add the Type column.

How many rows can I export? Up to 2,000 per export; split big spaces by date with created.
